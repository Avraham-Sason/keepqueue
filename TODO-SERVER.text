Conventions
- Messaging: SMS and Email notifications
- Deployment: Docker
- API base paths: /actions (mutations) and /data (queries) as mounted in `src/main_router.ts`
- In-memory cache: CacheManager singleton loads all Firestore at startup; /data routes query cache, /actions mutate Firestore + update cache
- Validation: Zod schemas via validateBody<T>(schema) middleware
- Responses: jsonOK(data) / jsonFailed(error) wrappers
